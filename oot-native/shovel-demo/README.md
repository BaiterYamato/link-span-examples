# Shovel Demo (OoT)

Standalone mod that proves Link-Span's newer OoT contracts: asset preflight, an item with a stable key, use by child
Link and V2 registration with an owner. The Megaton Hammer icon and model are placeholders, because this package does
not ship third-party assets. It is **not** a copy of Skijer's shovel and is not meant to be a final gameplay mod.

With NEI loaded, the demo grants NEI's own shovel. It shows up on the second inventory page, in the last row, and can be
equipped from the menu. A placeholder shovel already equipped by an earlier version of the demo is swapped for the NEI
shovel. Without NEI, the demo keeps its own item on a C button: on solid ground, each use creates a green rupee in
front of Link. That standalone item has no inventory cell. The placeholder icon and model are still unsuitable for a
main playthrough.
